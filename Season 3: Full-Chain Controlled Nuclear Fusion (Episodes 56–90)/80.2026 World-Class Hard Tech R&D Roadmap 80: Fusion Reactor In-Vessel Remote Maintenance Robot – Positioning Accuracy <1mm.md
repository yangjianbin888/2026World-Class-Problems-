**Abstract**
Remote maintenance is the operational linchpin of a fusion reactor. The 60-point baseline for in-vessel robots relies on articulated arms with end-effector positioning accuracy of 3-5 mm, which is insufficient for delicate tasks like replacing blanket modules, aligning diagnostics, or repairing first-wall tiles. The fundamental challenge is a combination of **kinematic chain compliance** (deflection under load), **thermal drift** (temperature gradients in the vacuum vessel), and **sensor noise**. Current approaches use "teach-and-repeat" or laser tracking, but these are slow and often require human intervention, violating the "no-human-in-the-loop" principle for a high-radiation environment. This roadmap proposes a **hybrid positioning system** based on (a) a **rigid, low-compliance articulated arm** with (b) **distributed, radiation-hardened eddy-current sensors** for local pose estimation, and (c) a **global, fiducial-based optical reference system** (using a LiDAR or a multi-camera system) for absolute positioning. The target is to achieve an end-effector positioning accuracy of <1mm in all six degrees of freedom under operational conditions.

**1. Pain Point Definition (Why)**
- **Kinematic Compliance:** The long, lightweight arms needed to reach into the torus have significant structural compliance. Under a moderate load (e.g., 5 kg for a tool), the deflection can be 1-2 mm at the tip.
- **Thermal Drift:** The vacuum vessel is not isothermal; temperature gradients of 10-20°C across the structure cause thermal expansion, shifting the base positions and the link lengths. This thermal drift changes the kinematic calibration, making an "absolute" position unreliable.
- **Sensor Noise:** Traditional encoders (optical or magnetic) in the joints have a cumulative error. Furthermore, the high radiation and gamma background can cause sensor drift or failure over time.

**2. The 60-Point Ceiling (Old Route)**
The 60-point baseline uses a "teach-and-repeat" method: an operator uses a master-slave manipulator to manually guide the robot through a task, and then the robot repeats the recorded trajectory. This approach is slow and does not account for any deviations (e.g., thermal drift, tool wear). It also requires the operator to be in the room, which is impractical in a high-radiation environment. *The 60-point ceiling has exhausted all headroom for parameter tuning – further adjustments only reduce efficiency, and any significant improvement requires a fundamental hardware change.*

**3. The Breakthrough Solution (What)**
**Core Concept:** A three-pronged, synergistic positioning system:
1.  **Structural Rigidity:** A low-compliance articulated arm made of a high-modulus material (e.g., a carbon-fiber-reinforced polymer or a dense ceramic, if radiation-resistant) or a pre-stressed steel structure to minimize deflection.
2.  **Local Pose Estimation:** A set of radiation-hardened eddy-current sensors embedded in the arm's joints and along its links. These sensors measure the relative displacement between link segments, providing high-speed (1 kHz) local position feedback.
3.  **Absolute Positioning:** A global reference system using a LiDAR or a multi-camera array that sees a set of passive fiducial markers (e.g., retro-reflective spheres) placed in the vessel. This provides absolute 3D positioning of the end-effector.
4.  **Sensor Fusion:** A Kalman filter or an equivalent real-time fusion algorithm that combines the local sensor data (kinematic state) with the global absolute data to achieve a final accuracy of <1mm.

**Parameter Benchmarking:**
- **Positioning Accuracy (End-Effector):** Baseline 3-5 mm → Target <1 mm.
- **Cycle Time (for a blanket module change):** Baseline >20 hours → Target <8 hours.
- **Repeatability:** Baseline ±2 mm → Target ±0.5 mm.
- **Maximum Payload:** Baseline 5 kg → Target 15 kg.

**4. Implementation Path (How)**
