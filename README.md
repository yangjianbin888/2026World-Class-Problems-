- **60分基线**：现有通用学术方案或工业标准，已触及性能天花板。
- **90分目标**：引入全新多维度闭环架构，实现量级跃迁（成本降50%或性能提2倍）。

### 留白策略与参数反推机制
最后10分的关键参数（如现场阻抗匹配、微观应力校准、工况依赖系数）**不给定固定死值**，全部使用标准工程句式：

> **“此处需根据现场实测数据 [X] 反推 [Y]。”**

**其中 [X] 的获取必须符合以下物理约束：**
[X] 须为可直接测量的物理量（温度、压力、电压、尺寸等），或已知牌号材料的公称标称值（屈服强度、电阻率、热导率等），或可通过标准检测方法（ISO/ASTM/GB等）在24小时内获取的值。
**严格禁止**任何“需定制、需采购进口设备、需开发新检测方法、需送外机构且周期>72小时”才能获取的 [X]。

**若现场无法直接测得 [X]，按以下优先级处理：**
1. **优先**：输出可测替代参数（如用表面硬度替代残余应力）。
2. **次优**：若无可直接替代，提供估算模型（如通过热平衡方程反推界面温度）。
3. **底线**：若估算模型不可行，提供物理上界推算（最坏情况下参数不超过某值，本方案在该上界内仍能运行）。
4. **兜底**：只有以上全部尝试失败后，方可判定：“人类工具链未达标，非本方案之过。”
