## 一、 项目定位

**这不是学术综述，也不是政策建议书。**

本项目是一套面向量产工程与基础科学前沿的硬核卡点数据库。本库以系统控制论和热力学定律为底层基线，系统梳理了人类当前在物理、工程、生命科学及社会工程领域面临的核心发展瓶颈，共收录 **530 项** 具备量化指标、物理边界与工程闭环条件的科研卡点，覆盖十七个关键技术领域。

本库的核心交付物是 **可落地、可验证、可量产的工程坐标**。每一个条目均可独立拆解为完整的研发闭环方案（90分量产级），拒绝泛泛而谈的学术愿景。

---

## 二、 核心评估准则（验证铁律）

本库所有条目的推演与建立，均严格遵循以下十字铁律：

> **逻辑可闭环，物理可复现。**

本库不收录任何无法证伪的空泛论述。脱离这两条，即视为无效推演或民科。每一条目必须包含：可量化指标（物理阈值或工程参数）、可溯源的物理/数学机理、明确的失效边界条件、多技术路线的优劣对比分析。

## 三、 工程落地的三条执行规则

本库所有量产产业级条目（编号 1–490）严格遵循以下执行规则：

### 1. 材料与组件准则
**强制采用现货级（COTS）工业标准品。** 严禁指定单一供应商或商业型号，仅定义公开的工业标准、性能指标与参数阈值。若需特殊工艺，必须证明其无法通过公开市场采购获得，并提供其物理常数（熔点、晶格常数、屈服强度等）的公版描述，否则归零重构。

### 2. 鲁棒性优先
**鲁棒性优先于极致性能。** 所有设计必须兼顾成本、耐用性与容错率。方案以**人类60分通用方案**为基线，目标锁定**90分量产级**，需实现量级跃迁（如成本降50%或性能提2倍）。

### 3. 表述与数据呈现规范
**剥离一切主观立场、空话与模糊表述。** 仅保留物理参数、量化阈值与失效模式。所有行业黑话须用自然物理语言备注定性。**全文禁用表格**，参数对比使用纯文本流加箭头“→”明确因果关系，确保数据检索（Grep）友好、抗失真。

## 五、 典型条目结构

每一条目均按照统一模板编写，包含以下核心要素：

**【编号与名称】** 如：`1. EUV光源：锡滴（Sn）靶等离子体转换效率（CE>6%）与碎屑污染`
**【痛点定义】** 现有60分方案的失效模式与物理极限
**【破局方案】** 反共识设计或关键物理路径（一句话核心架构）
**【参数对标】** 人类基线60分 vs 本方案90分最优解（体现量级变化）
**【供应链锚定】** COTS工业标准定义（严禁指定具体供应商）
**【实施路径】** 步骤 A → B → C，每步含验收标准（量化指标）
**【最终鉴定】** 保守级改良 vs 破局级颠覆（以是否实现量级跃迁为判定标准）
**【留白/虚轴】** 保留冗余自由度，关键参数使用标准句式标注：`“此处需根据现场实测数据 [X] 反推 [Y]。”`
**【证伪红线】** 间接测量兜底失败后方可判定“人类工具链未达标，非本方案之过”
**【预判质询】** 3–5条最致命质疑 + 一句物理回应
**【SEO关键词】** 长尾关键词标签

## 六、 质量标准与参数留白策略

### 评分锚点
- **60分基线**：现有通用学术方案或工业标准，已触及性能天花板。
- **90分目标**：引入全新多维度闭环架构，实现量级跃迁（成本降50%或性能提2倍）。

### 留白策略与参数反推机制
最后10分的关键参数（如现场阻抗匹配、微观应力校准、工况依赖系数）**不给定固定死值**，全部使用标准工程句式：

> **“此处需根据现场实测数据 [X] 反推 [Y]。”**

**其中 [X] 的获取必须符合以下物理约束：**
[X] 须为可直接测量的物理量（温度、压力、电压、尺寸等），或已知牌号材料的公称标称值（屈服强度、电阻率、热导率等），或可通过标准检测方法（ISO/ASTM/GB等）在24小时内获取的值。
**严格禁止**任何“需定制、需采购进口设备、需开发新检测方法、需送外机构且周期>72小时”才能获取的 [X]。

**若现场无法直接测得 [X]，按以下优先级处理：**
1. **优先**：输出可测替代参数（如用表面硬度替代残余应力）。
2. **次优**：若无可直接替代，提供估算模型（如通过热平衡方程反推界面温度）。
3. **底线**：若估算模型不可行，提供物理上界推算（最坏情况下参数不超过某值，本方案在该上界内仍能运行）。
4. **兜底**：只有以上全部尝试失败后，方可判定：“人类工具链未达标，非本方案之过。”
