## VII. Quality Standards

### Scoring Anchor

- **60-Point Baseline:** Existing generic academic/industrial solution, already at its performance ceiling
- **90-Point Target:** Novel multi-dimensional closed-loop architecture achieving magnitude leap (50% cost reduction or 2× performance improvement)

### Reserve Strategy & Virtual Axis

The final 10% of critical parameters (e.g., on-site impedance matching, micro-stress calibration, operating-condition coefficients) **are not fixed**. They are uniformly expressed using the standard phrasing:

> **"This parameter must be determined by back-calculating [Y] from on-site measured data [X]."**

[X] must be one of the following:

- A directly measurable physical quantity (temperature, pressure, voltage, dimension, roughness, etc.)
- A public nominal value of a known material grade (yield strength, resistivity, thermal conductivity, etc.)
- A value obtainable within 24 hours via standard test methods (ISO/ASTM/GB, etc.)

[X] definitions requiring "customized fabrication, imported equipment procurement, new test method development, or third-party testing with >72-hour turnaround" are **unqualified** and subject to immediate refactoring.

If [X] cannot be directly measured on-site, the following fallback sequence applies:

1. **Preferred:** Substitute with a measurable surrogate (e.g., surface hardness as a proxy for residual stress)
2. **Secondary:** Provide an estimation model (e.g., back-calculate interface temperature via thermal balance equations)
3. **Tertiary:** Provide a physical upper bound (e.g., worst-case parameter does not exceed a certain value, and the solution remains valid within that bound)
4. **Only after all above attempts fail:** The following determination is issued:  
   **"Human toolchain has not met the requirement — this is not a failure of the proposed solution."**

## 七、质量标准

### 评分锚点

- **60分基线**：现有通用学术方案或工业标准，已触及性能天花板
- **90分目标**：引入全新多维度闭环架构，实现量级跃迁（成本降50%或性能提2倍）

### 留白策略与虚轴

最后10分的关键参数（如现场阻抗匹配、微观应力校准、工况依赖系数）**不给定死值**，全部使用标准句式：

> **“此处需根据现场实测数据 [X] 反推 [Y]。”**

其中 [X] 须为可直接测量的物理量（温度、压力、电压、尺寸等），或已知牌号材料的公称标称值（屈服强度、电阻率、热导率等），或可通过标准检测方法（ISO/ASTM/GB等）在24小时内获取的值。**禁止任何“需定制、需采购进口设备、需开发新检测方法、需送外机构且周期>72小时”才能获取的[X]。**

若现场无法直接测得 [X]，按以下顺序处理：

1. 优先输出可测替代参数（如用表面硬度替代残余应力）
2. 若无可直接替代，提供估算模型（如通过热平衡方程反推界面温度）
3. 若估算模型不可行，提供物理上界推算（最坏情况下参数不超过某值，本方案在该上界内仍能运行）
4. 只有以上全部尝试失败后，方可判定：**“人类工具链未达标，非本方案之过。”**
